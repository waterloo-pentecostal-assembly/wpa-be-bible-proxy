Admin sign-in

Only admins can use this console. Sign in with your Firebase account; its Firestore profile users/{uid} must have is_admin: true.

Sign-in isn't set up on this server: it has no Firebase web config for the admin project. Add it to src/config/firebase-client-config.json (or mount the file at /etc/secrets/), then restart the proxy.

Use an ID token instead

Pasted tokens can't be refreshed and stop working within an hour.
